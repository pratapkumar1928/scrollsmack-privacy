# ScrollSmack — privacy policy

Public host for the [ScrollSmack](https://github.com/pratapkumar1928/scrollsmack)
Android app's privacy policy, which Google Play requires to be reachable at a
public URL.

Live: **https://pratapkumar1928.github.io/scrollsmack-privacy/**

- `index.html` — what Play and users actually read.
- `privacy-policy.md` — same text in Markdown, mirrored from `docs/privacy-policy.md`
  in the app repo. Edit it there first, then copy it here, so the two can't drift.

Nothing else belongs in this repo. The app source stays private.
